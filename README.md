# The Homeowner's Field Manual

This repository is the canonical working knowledge base for the AI-assisted creation of **The Homeowner's Field Manual**.

It exists so ChatGPT, Claude, Codex, and other AI tools can work on the book without the author having to repeatedly restate its structure, design rules, writing rules, production constraints, and prior decisions.

## For AI tools

**Start with [`Instructions_for_AI_Tools.md`](Instructions_for_AI_Tools.md).**

That file defines the required read order, authority hierarchy, and locations of the book's canonical specifications.

Do not reorganize, rename, consolidate, or substantially restructure this repository unless the author explicitly requests it. The separation and filenames are intentional because AI tools depend on stable, predictable sources of truth.

## For humans

The current page-by-page book structure is maintained in [`toc.csv`](toc.csv).

Other Markdown files define specific aspects of the project, such as print specifications, page/spread rules, writing rules, visual design, diagrams, forms, page codes, editions, terminology, and production workflow.

When a project decision changes, update the single authoritative file for that subject rather than duplicating the change across multiple documents.
