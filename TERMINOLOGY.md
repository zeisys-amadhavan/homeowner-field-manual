# Terminology

This file defines recurring vocabulary that should remain consistent across the book.

Add terms only when inconsistent naming would create confusion.

## Book terms

### Form
The homeowner-fillable **left / even** page that records the reader's own house.

### Guide
The explanatory **right / odd** page paired with a form.

### Diagram
The primary visual explanation on a guide page.

### Spread
A paired left and right page addressing one subject.

### Spread Goal
The single outcome the reader should achieve after using the spread. Canonical wording lives in `toc.csv`.

### Page Code
The permanent section-letter + sequence identifier such as `E04` or `F18`.

### Tier
One of the content-depth classifications: Basic, Advanced, or Professional.

### Document of truth
The completed book as a concise factual record of the homeowner's actual property.

## Preferred ownership language

Prefer **homeowner** or **owner** for the reader.

Prefer **house** when discussing the physical dwelling/system and **home** when the broader lived context is intended.

Use **property** when land, legal ownership, or the full parcel is intended.

## Technical naming rule

Use the simplest technically correct term a homeowner is likely to encounter in real life.

When two common terms exist, choose one preferred term for headings and explain the alternative once if useful.

## Adding terminology

When a recurring naming conflict appears during production, add the preferred term here rather than resolving it differently on each page.
